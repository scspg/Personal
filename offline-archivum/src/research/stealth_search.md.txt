# Anti-bot / CAPTCHA-mentes letöltés és keresés AI agentnek: kutatási jelentés (2026-11-14)

**Ellenőrzés módja**
- Verziók és dátumok: PyPI JSON API és npm registry.
- Repók: `git ls-remote` és shallow clone. Innen jönnek a LICENSE fájlok, az utolsó commit dátuma és a README/pyproject részletek.
- Árak: a hivatalos pricing oldalak, WebFetch-csel letöltve (2026-11-14).
- A kódrészletek API-ját a README-kből és a forráskódból ellenőriztem, **élesben nem futtattam őket**. A sandbox TLS-t bontó (MITM) agent proxyn keresztül megy ki, így itt a TLS-fingerprint teszt értelmetlen lett volna.
- Ahol valamit nem tudtam ellenőrizni, ott `UNVERIFIED` a jelölés.

## (b) Döntési tábla

| Helyzet / tünet | Első választás | Ha nem megy | Megjegyzés |
|---|---|---|---|
| Sima fájl (PDF/ZIP) letöltése; `curl` → 403, de a böngészőben megnyílik; a válaszban **nincs** `cf-mitigated: challenge` header | **curl_cffi** `impersonate="chrome"` (+ teljes böngésző-headerek, Referer) | Scrapling `Fetcher` vagy `FetcherSession`; utána Camoufox | A TLS/JA3 és HTTP/2 fingerprint a leggyakoribb ok. MITM proxy mögött hatástalan. |
| 403 vagy 503 + „Just a moment…” HTML, `cf-mitigated: challenge` header (JS challenge vagy Turnstile) | **Camoufox** (`humanize=True`, headful/virtual), vagy **Patchright** `channel="chrome"`, headful | Scrapling `StealthyFetcher(solve_cloudflare=True)`, SeleniumBase CDP Mode `sb.solve_captcha()` | A cookie átadható a curl_cffi-nek, de a cf_clearance UA-hoz és IP-hez kötött. |
| Sok URL ugyanarról a védett site-ról, nyelvfüggetlen pipeline | **Byparr** vagy **FlareSolverr** (Docker, `POST /v1`) → cookie + UA → curl_cffi | Camoufox, perzisztens profillal | Csak 127.0.0.1-re bindolva szabad futtatni. |
| Webes keresés (források felkutatása) | **SearXNG** (saját példány, JSON) vagy **ddgs** | **Brave Search API** (~1k ingyen/hó), Serper (2 500 ingyen), Exa vagy Tavily | Google-t közvetlenül ne scrape-eljünk. A Bing API megszűnt, a Google CSE új ügyfélnek zárva. |
| Oldal szövegét kell Markdownként archiválni | **Crawl4AI**, vagy `r.jina.ai/<url>` (20 RPM kulcs nélkül) | Firecrawl (cloud) | Binárisokhoz curl_cffi vagy böngésző-download kell. |
| Nagyon erős védelem (Akamai, Datadome, Kasada) vagy datacenter IP-ről minden blokkolva | **Residential proxy** + Camoufox `geoip=True` | **Cloud unblocker**: Zyte (olcsó könnyű site-on), Bright Data Web Unlocker ($1.5/1k), ZenRows, Scrapfly | A GB-díjas (Oxylabs, Bright Data Browser) nagy fájloknál drága, a kérésenkénti díjas jobb. |
| Interaktív folyamat (űrlap, lapozó, „I agree” gomb) | Patchright vagy Camoufox, scriptelve | Browser Use (LLM-vezérelt), Browserbase vagy Steel cloud | Az LLM-agent drága és lassú, tömeges munkára nem való. |
| Interaktív CAPTCHA (reCAPTCHA, hCaptcha) | **Más forrás keresése** (tükör, Wayback, kiadói repo) | CAPTCHA-solver API ($0.6–3/1k) | ToS- és jogi kockázat, lásd lent. |
| JS-renderelés nagy tömegben, védelem nélkül | **Lightpanda** (CDP) | Playwright, headless | Nem stealth eszköz. |

**Residential proxy.** A legtöbb 403 oka az IP-reputáció (datacenter ASN), nem a böngésző. A Camoufox és az undetected-chromedriver README-je is kiemeli, hogy datacenter IP-ről „chances are large you will not pass”. Ha minden eszköz elbukik, előbb a proxyt kell kipróbálni (Camoufox: `proxy={...}, geoip=True`, hogy a timezone, locale és WebRTC egyezzen az IP-vel). Residential proxy ára a szponzori README-k szerint kb. $0.3–8/GB.

**Rate-limit etikett.** Egyszerre 1–2 kapcsolat domainenként. A kérések között 2–10 s véletlen késleltetés legyen. A `Retry-After` headert és a 429-et tartsuk be, exponenciális backoffal. Cache-eljünk (ETag / If-Modified-Since), és ugyanazt a fájlt ne töltsük le kétszer. Éjszakai, kis forgalmú idősávban fussunk. Legyen azonosítható a kapcsolattartás, ha a site kéri.

**robots.txt / ToS.** Archiválás előtt nézzük meg a robots.txt-t és a felhasználási feltételeket. Sok humanitárius forrás (Sphere, Peace Corps, ECHO) kifejezetten engedi a dokumentumok letöltését és terjesztését, de a licencet (gyakran CC-BY-NC vagy hasonló) rögzíteni kell a metaadatban. A Cloudflare-blokk a forgalom szűrésére szolgál, nem tiltja a tartalom felhasználását. A tömeges, agresszív kérés viszont ToS-sértés lehet. CAPTCHA-solvert csak akkor használjunk, ha nincs más legitim út.

### 1. Camoufox: oldal mentése + fájl letöltése

```python
# pip install -U "camoufox[geoip]" && camoufox fetch
from pathlib import Path
import base64
from camoufox.sync_api import Camoufox

PAGE_URL = "https://example.org/resources"
FILE_URL = "https://example.org/files/manual.pdf"
OUT = Path("archive"); OUT.mkdir(exist_ok=True)

# headless="virtual" (Linux, Xvfb) stealthebb, mint a headless=True
with Camoufox(headless=True, humanize=True) as browser:   # proxy={"server": "...", "username": "...", "password": "..."}, geoip=True
    page = browser.new_page()
    page.goto(PAGE_URL, wait_until="domcontentloaded", timeout=90_000)
    page.wait_for_load_state("networkidle")        # itt fut le a JS-challenge
    (OUT / "page.html").write_text(page.content(), encoding="utf-8")

    # A) Navigáció, ami letöltést indít (Content-Disposition: attachment)
    try:
        with page.expect_download(timeout=120_000) as dl_info:
            try:
                page.goto(FILE_URL)
            except Exception:
                pass                                # Playwright: "Download is starting" -> várt hiba
        dl = dl_info.value
        dl.save_as(OUT / dl.suggested_filename)
    except Exception:
        # B) Fallback: in-page fetch a böngésző saját TLS-ével és cookie-jaival (kis/közepes fájlra)
        b64 = page.evaluate("""async (u) => {
            const r = await fetch(u, {credentials: 'include'});
            if (!r.ok) throw new Error('HTTP ' + r.status);
            const b = new Uint8Array(await r.arrayBuffer());
            let s = ''; for (let i = 0; i < b.length; i += 0x8000) s += String.fromCharCode(...b.subarray(i, i + 0x8000));
            return btoa(s);
        }""", FILE_URL)
        (OUT / Path(FILE_URL).name).write_bytes(base64.b64decode(b64))
        # Ha az isolated world-ben a fetch nem megy: Camoufox(main_world_eval=True), és "mw:"-prefixes evaluate.
```

### 3. curl_cffi: böngésző-TLS-t utánzó streamelt letöltés

```python
# pip install curl_cffi --upgrade
from pathlib import Path
import curl_cffi

URL = "https://example.org/files/manual.pdf"
OUT = Path("archive") / Path(URL).name
OUT.parent.mkdir(exist_ok=True)

with curl_cffi.Session(impersonate="chrome") as s:     # "firefox", "safari", vagy fix pl. "chrome124"
    r = s.get(URL, stream=True, timeout=120,
              headers={"Referer": "https://example.org/"})  # proxies={"https": "http://user:pass@host:port"}
    if r.status_code == 403 and r.headers.get("cf-mitigated") == "challenge":
        r.close()
        raise SystemExit("JS challenge -> böngésző (Camoufox/Patchright) vagy Byparr/FlareSolverr kell")
    r.raise_for_status()
    with open(OUT, "wb") as f:
        for chunk in r.iter_content():
            f.write(chunk)
    r.close()

# Cookie-átadás FlareSolverr/Byparr után: ugyanaz a User-Agent kell, cookies={"cf_clearance": "..."};
# Camoufox-cookie-hoz impersonate="firefox" illik (curl_cffi 0.17: firefox -> firefox155).
```

## (d) Mire figyeljen az AI

1. **Diagnosztizáljon, mielőtt eszközt vált.** Nézze meg a státuszkódot, a `server: cloudflare` és a `cf-mitigated: challenge` headert, valamint a „Just a moment…” vagy Turnstile jelenlétét. Ha nincs challenge, curl_cffi elég. Ha van, böngésző kell. Ha minden 403, az IP-vel van baj.
2. **Mindig a legolcsóbb működő réteggel kezdjen.** Sorrend: curl_cffi → Byparr/FlareSolverr cookie-val → Camoufox vagy Patchright → residential proxy → cloud unblocker → (kivételesen) CAPTCHA-solver.
3. **Ne használjon elavult eszközt.** A cloudscraper (PyPI 2023), a puppeteer-extra-plugin-stealth (2023), az undetected-chromedriver (2024), a hrequests (2024) és a playwright-stealth modern Cloudflare ellen nem működik. A Bing Search API 2025-08-11-én megszűnt; a Google CSE új ügyfélnek zárva van, és 2027-01-01-gyel leáll.
4. **TLS-t bontó (MITM) proxy mögött a TLS-impersonation hatástalan**, mert a célszerver a proxy fingerprintjét látja. Ilyenkor böngésző vagy külső hálózat kell.
5. **Legyen konzisztens az identitás.** A cf_clearance cookie UA-hoz és IP-hez kötött. A cookie-t kinyerő böngésző és a letöltő kliens ugyanazt a UA-t, IP-t és lehetőleg ugyanazt a böngészőcsaládot használja (Camoufox → `impersonate="firefox"`, Chrome → `"chrome"`). Patchrightnál ne állítson saját UA-t vagy headert.
6. **Headful jobb, mint headless.** Szerveren `xvfb-run` vagy Camoufox `headless="virtual"`. Képblokkolást (`block_images`) és animáció-kikapcsolást ne használjon védett oldalon, mert detektálható.
7. **Keresni API-val vagy saját SearXNG-vel kell, nem Google-scrape-pel.** Kis volumenre a ddgs vagy a SearXNG ingyenes; megbízhatóbb a Brave ($5/1k, ~1k ingyen/hó), a Serper ($0.30–1/1k, 2 500 ingyen) vagy az Exa ($4–7/1k, havi $10 ingyen).
8. **Mielőtt bypassol, keressen alternatív forrást.** Ilyen a hivatalos tükör, a kiadói repository, a `web.archive.org/web/2id_/<URL>` (az `id_` a nyers eredeti fájlt adja), vagy ugyanaz a dokumentum másik szervezet oldalán. Ez gyakran gyorsabb és jogilag tisztább.
9. **Udvariasan töltsön le.** Domainenként 1–2 párhuzamos kapcsolat, 2–10 s jitter, 429 vagy `Retry-After` esetén backoff, és sose töltse le kétszer ugyanazt (hash vagy ETag). Minden fájlhoz naplózza: forrás-URL, dátum, HTTP-státusz, SHA-256, licenc.
10. **CAPTCHA-solvert és cloud unblockert csak tudatos döntéssel használjon.** Pénzbe kerül, harmadik fél látja az URL-eket, és ToS-kockázatot jelent. A GB-alapú díjazás nagy PDF/ZIP-gyűjteménynél gyorsan elszáll. A Firecrawl a 403-as választ is felszámolja.
