# Offline LLM archívum: uncensored/abliterated és kis modellek, runtime-ok (állapot: 2026-11-14)

A kért szűrést alkalmaztam: csak a legújabb generációs bázisokra épülő modellek szerepelnek. Az elavult bázisokat (Qwen2.5, Llama 3.x, Gemma 3, Qwen3.5-122B és -397B, GLM-4.x, Mistral Small 3.x) kihagytam, a végén listázom őket. A bázis megjelenési dátuma (`base_created`) a HF API `createdAt` mezője.

**Ellenőrzési módszer**
- **HF API**: model info és a `tree/main?recursive=true` lista. A quant-méreteket python3 -I-vel összegeztem a split részekkel együtt. A méretek decimális GB-ban vannak (10^9 byte).
- **GitHub**: az API és a github.com web 403-at adott a proxy mögött. Helyette `git ls-remote --tags` adta a repo létezését és a legutolsó taget, sparse `git clone` a flageket a forráskódból, WebFetch pedig a `releases/expanded_assets/<tag>` oldalakat.
- **PyPI**: a verziókhoz.
- **UGI leaderboard**: a Space `ugi-leaderboard-data.csv` fájlja (frissítve 2026-10-17). Qwen3.8 alapú modell még nincs benne.
- **Jelölések**: `verified_api` = HF API-ból összegezve. `unverified` = nem ellenőrzött vagy következtetett adat.

## 1. Módszerek röviden

- **Abliteration (refusal-direction orthogonalization)** (Arditi et al. 2024, arXiv 2406.11717)
  - A residual stream aktivációiból kiszámítja a "harmful − harmless" átlagkülönbséget. Ez a refusal irány.
  - Ezt kivetíti azokból a súlymátrixokból, amelyek a residual streambe írnak (attn output, MLP/FFN down).
  - Változatai: projected és norm-preserving/biprojected (MPOA), valamint rank-2 subspace.
  - Az mrfakename DeepSeek-V4.1 kártya szerint a chat és a think mód külön irányban utasít el.
  - Az mrfakename kártya mérése: refusal 97→4 (chat), 98→9 (think), first-token KL 0.067.
  - A huihui-ai most már közvetlenül GGUF-on abliterál a llama.cpp `cvector-generator`-ral. A nagy modelleknél "patch" GGUF-ot ad, amit az unsloth quantra kell ráfuttatni a repóban lévő python scripttel.
- **Heretic**
  - Repo: `https://github.com/p-e-w/heretic` (git-tel ellenőrizve). Legutolsó tag v2.1.0, PyPI `heretic-llm` 2.1.0, 2026-11-08. Python ≥3.10, PyTorch 2.6+.
  - Automatikus Optuna TPE keresés, ami a refusal rate-et és a KL divergence-et együtt minimalizálja.
  - A v2 default modifier az ARA (Arbitrary-Rank Ablation). Klasszikus abliteration is választható, MPOA/projected opciókkal.
  - `quantization = bnb_4bit` opció VRAM spóroláshoz. Configfájl: `config.toml`, vagy a `HERETIC_CONFIG_FILE` env változó. A v1-es configok nem kompatibilisek a v2-vel.
  - Saját magad is futtathatod offline (a forrásban ellenőrzött datasetekkel):
    ```bash
    pip install -U heretic-llm   # online gépen, majd wheel-ek: pip download heretic-llm -d wheels/
    hf download Qwen/Qwen3.5-4B --local-dir models/Qwen3.5-4B
    hf download mlabonne/harmful_behaviors --repo-type dataset
    hf download mlabonne/harmless_alpaca --repo-type dataset
    # offline gépen:
    HF_HUB_OFFLINE=1 heretic models/Qwen3.5-4B
    ```
    A README szerint egy 4B modell RTX 3090-en kb. 30–40 perc.
- **SFT-alapú "decensoring"**
  - Dolphin, Hermes: általános low-refusal fine-tune.
  - NousResearch **Arete-27B**: a régi Perplexity R1-1776 utóda (lásd A11).

## 5. Letöltés, ellenőrzés, tárolás

- **Hugging Face CLI**: a `huggingface_hub` 2.4.0 wheel egyetlen CLI entry pointja a `hf`. A `huggingface-cli` már nincs benne.
  - Paraméterek (a download.py-ban ellenőrizve): `--include`, `--exclude`, `--local-dir`, `--cache-dir`, `--force-download`, `--dry-run`, `--max-workers`, és ugyanott a `--repo-type dataset` használat is.
  ```bash
  pip install -U huggingface_hub hf_xet
  export HF_XET_HIGH_PERFORMANCE=1    # a HF_HUB_ENABLE_HF_TRANSFER deprecated
  hf download mradermacher/Qwen3.5-4B-heretic-2.0-GGUF --include "*Q4_K_M*" "*mmproj-Q8_0*" --local-dir /archive/llm/qwen35-4b-heretic
  hf download huihui-ai/Huihui-GLM-5.3-Flash-abliterated-GGUF --include "UD-Q4_K_XL/*" --local-dir /archive/llm/glm53flash --max-workers 8
  ```
  Megszakadás után ugyanazt a parancsot kell újra futtatni, és folytatja.
- **aria2c párhuzamos letöltés**: az URL minta `https://huggingface.co/OWNER/REPO/resolve/main/PATH`. A publikus fájl 206-ot adott range kérésre, ezt ellenőriztem.
  ```bash
  aria2c -x16 -s16 -k10M -c -d /archive/llm "https://huggingface.co/unsloth/Qwen3.5-9B-GGUF/resolve/main/Qwen3.5-9B-Q4_K_M.gguf"
  # gated: --header="Authorization: Bearer $HF_TOKEN"
  ```
- **sha256 ellenőrzés**: a tree API `lfs.oid` mezője a sha256.
  - Például a `Qwen3.5-0.8B-Q4_K_M.gguf` oid értéke `bd258782e35f7f458f8aced1adc053e6e92e89bc735ba3be89d38a06121dc517`.
  - A nagy repók `recursive=true` listája lapozott. A rhasspy/piper-voices-nál hiányos volt, ezért alkönyvtárra kérdezz (`tree/main/<subdir>`), vagy használd a `HfApi().list_repo_tree`-t.
  ```bash
  curl -sS "https://huggingface.co/api/models/OWNER/REPO/tree/main/SUBDIR" | python3 -I -c "import json,sys;[print(f['lfs']['oid']+'  '+f['path'].split('/')[-1]) for f in json.load(sys.stdin) if f.get('lfs')]" > SHA256SUMS
  sha256sum -c SHA256SUMS --ignore-missing
  ```
- **Fájlrendszer**: FAT32-n a fájlméret limit 4 GB, ezért exFAT, ext4 vagy NTFS kell.
  - Ha mégis FAT32: `llama-gguf-split --split-max-size 3G in.gguf out` (a flag a forrásban ellenőrizve).
  - Összefűzés: `llama-gguf-split --merge in-00001-of-0000N.gguf out.gguf`. Erre ritkán van szükség, mert a llama.cpp az első részről betölti a teljes splitet.
- **Gated repók**:
  - A legtöbb modellhez nem kell regisztráció.
  - A Llama (pl. meta-llama/Llama-3.2-3B-Instruct, Llama-4-Scout) `gated=manual`; a resolve URL 401-et ad. Kell HF fiók, a license elfogadása és token (`hf auth login` vagy `HF_TOKEN`).
  - A Gemma 4 NEM gated, a Gemma 3 még igen.
  - A Uniboshi Kimi-K3 és az orcarouter MiniMax `gated=auto`, ezekhez login és kattintás kell.
